# Передача работы: реалистичный 3D-персонаж (Secure Student Portal)

Отвечать по-русски, кратко. Репозиторий: `Mini-Project-Secure-Student-Portal` (сначала прочитай его CLAUDE.md).

## Правила пользователя
- Коммиты и пуш делает пользователь сам. Давать только команды PowerShell, каждую в отдельном блоке. Готовое пушится в ветку `front`.
- Фронтенд: строгий CSP (без inline-скриптов и `style=""`), простой читаемый код, без «нейрослопа».
- Тестировать только своё приложение на localhost. Тег `v1-vulnerable` не трогать.
- Фото людей в репозиторий не класть. Персонажи похожего типа, не копии людей. Персонажей и интерфейс GTA не копировать.

## Задача
Персонаж справа в портале и его редактор должны выглядеть реалистично, по референсам (16 фото, 6 человек; фото пользователь пришлёт заново). Типажи:
- причёски: «шторка», рваная чёлка, чёлка набок, средние волнистые, длинные волнистые, убранные назад с хвостом;
- лица: мягкая челюсть, миндалевидный глаз, прямые брови, борода только на подбородке, лёгкая щетина, родинки, высыпания на щеках, широкое лицо, чуть приоткрытый рот;
- одежда: худи на молнии поверх белой футболки, вязаный кардиган, поло с белым кантом, бежевая футболка, тонкая оправа с двойным мостом;
- мягкий комнатный свет.

## Файлы (src/main/resources/static)
- `js/human.bin`: сетка и формы MakeHuman, CC0, 2,7 МБ (собран скриптом `_character-wip/prep.py`).
- `js/avatar-human.js`: смешивание форм, поза, Catmull-Clark, сетки расстояний (trunk/arm/leg/head), `skin`, `scatter`, `FACE`.
- `js/avatar-worker.js`: `person(c)` (функции расстояний из сеток), `clothes`, `accessories`, `HAIR`/`strands`, `build`.
- `js/avatar.js`: WebGL2, шейдеры, камера. Лицо раскрашивается по `vRest` (координаты нейтральной головы: глаза y≈.0012 x≈.033, кончик носа y≈-.035, линия губ y≈-.0675, подбородок y≈-.107).
- `js/character.js`, `css/character.css`: редактор и панель. Изменены также `app.html`, `js/app.js`.

## Как проверять
Инструменты в `_character-wip` (скопировать в свой scratchpad и работать там):
- Портал должен работать на 8094 (проверить, что отвечает; иначе `java -jar portal-v2-reactor.jar --server.port=8094` из MiniProj).
- `node dev.mjs`: статика с CSP на 8196, `/api` идёт на 8094. Путь к static прописан внутри.
- `bash run.sh m6.py`: применяет правки (`e.py`, функция `ed(file,(old,new),...)`), снимает кадры из `j.json`, собирает `all.png`. В `j.json` ширина кадра не меньше 1000, иначе включается мобильная вёрстка.
- `node slice.js` и `python slice.py`: срезы сеток расстояний. Нужен `human.bin` в static/js.
- Java: `C:\Program Files\Android\Android Studio\jbr` (JAVA_HOME). Длинные скрипты с кавычками писать файлом через Write, не через bash heredoc.
- Снимки требуют Chrome и Python с Pillow.
